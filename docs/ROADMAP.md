# Etivio roadmap (agreed 2026-10-22)

Built one item per session. Tick each one off when it ships.

1. [ ] Landing tracking: first landing page, referrer, UTM, country, device per visitor; admin Tracking report
2. [ ] SEO: metadata per page, Open Graph images, JSON-LD (Course, Product, Person), sitemap coverage, Search Console
3. [ ] AI for tutors: generate course outline, topics, lesson text, descriptions, quiz questions, thumbnails (image model)
4. [ ] AI for learners: lesson assistant that answers from the course content, summaries, practice questions
5. [ ] Files and marketplace: close the gaps in uploads and in showing files on the marketplace
6. [ ] Group buy: buy together at a discount
7. [ ] Coaches + booking: coach role goes live, availability, paid bookings, calendar emails
8. [ ] Video calling: 1:1 and group calls for bookings and live classes
9. [ ] Community: spaces, posts, join approval
10. [ ] Projects: coaches set briefs, students submit, public showcase

## Decisions
- Tutors and coaches stay separate roles on one account. Tutor = sells self-paced courses. Coach = sells live time
  (bookings, cohorts, project reviews). One person can hold both.
- Community join modes: open, request to join (owner approves answers), auto-join when the learner owns a linked
  course/product, invite link. Start with an official Etivio community plus course spaces.
